## 🧭 Funcionalidades principais

- Menu "hamburger" para navegação mobile
- Layout 100% responsivo (mobile-first, adapta para tablet e desktop)
- Botões de ação grandes e acessíveis para uso com o dedo/polegar
- Conteúdo leve, rápido para carregar
- Estrutura de CSS usando media queries, Flexbox e Grid
